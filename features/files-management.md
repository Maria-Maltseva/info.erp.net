# ERP.Net Files and Folders

Every single day employees in an organization create new value with every single document they generate – be it an offer, a contract, a manual, a how-to video, a product image, etc. 
These little pieces of business value become even more valuable as they get used again and again by all employees. 
Every reuse and every modification means saving time and preserving sources and efforts.

Today all these pieces of value are often scattered across different internal systems. 
But what if all the company’s files could be stored in a single repository, directly within its business management system?
ERP.Net does exactly that: stores all corporate files, making them accessible without leaving the business management platform. 
Employees no longer need to switch between multiple storage solutions or rely on external applications for word processing, spreadsheets, or similar tasks.

## What is ERP.Net File Management

File management in ERP.Net enables users to organize corporate files neatly, using folders in much the same way as physical drawers. 
Users can upload, store, edit, rename, move, and delete files. 
They can also create folders—and subfolders—in a classic tree structure.

The ultimate goal of folder management is to allow employees to perform all their daily work within ERP.Net, without depending on outside applications to create, edit, and manage files.

## How it Works

ERP.Net file management is very similar to the Windows file management. 
It relies on logical “drawers” – folders, where files get stored.

Any authorized user can create a new folder — or a subfolder within an existing one. 
Folders containing other folders are considered “parent” folders.

A folder may contain both files and subfolders. 
Within each folder, users can upload, open, edit, save, rename, move, and delete files.

Every folder may be moved, deleted, copied. 

A double click would open a file or a folder while right-clicking files or folders gives access to familiar options such as open, cut, copy, paste, and delete.

## Extra Value

The user may use the kebab menu in the top-right corner for additional options such as search, upload, and group files.

Accessing the larger kebab menu in the application ribbon allows for more advanced features like:

- - Discussion: Because ERP.net is a social ERP system, communication and collaboration are built into every area. Colleagues can discuss issues related to a specific folder or file. Tagging colleagues and @mentions would automatically notify the relevant users.
- - Security Management: Each file and folder can be open to everyone or restricted (“locked”) for access only by selected employees.

 ## Benefits

 To wrap up, ERP.Net file management provides several benefits:

 - __Centralized Storage__ – all corporate files are stored directly within ERP.Net, eliminating the need for external storage systems or third-party apps.
 - __Organized Structure__ – Hierarchical folder system makes it easy to group, sort, and navigate files, just like a physical filing cabinet.
 - __Improved Efficiency__ – Quick access to documents reduces time wasted searching across multiple systems. Bulk operations (copy, move, archive, backup) save effort.
 - __Seamless Workflow__ – Employees can create, edit, and manage files without leaving ERP.Net, keeping all work within a single platform.
 - __Enhanced Collaboration__ – Built-in discussion tools allow colleagues to comment, tag, and share feedback on files and folders, with real-time notifications.
 - __Access Control & Security__ – Folder-level permissions ensure sensitive information is only available to authorized employees.
 - __Familiar & Intuitive__ – The folder metaphor is instantly recognizable, lowering the learning curve for new users.
 - __Scalability & Reliability__ – Structured storage supports growth, making it easy to manage thousands—or millions—of files consistently.
